# cloud-infra

Common declarative infrastructure on the cloud.

## What this repo contains

Declarative configuration for deploying ORDES Cloud resources (e.g. on SWITCH
and Azure). This is meant for project-agnostic infrastructure.

- [k8s](components/k8s)
- [vm-ordes-main development VM](components/vm-ordes-main)
- [vm-gitlab-runner](components/vm-gitlab-runner)
- [vm-nix-cache](components/vm-nix-cache)
